# Predictive Input Buffer

Trajectory-based 1-2 frame press and wave release input buffer for Geometry Dash 2.2081 (Geode 5.11.2).
Doesn't matter if Click Between Frames is on.

## Hotkeys (in a level)
- **Right Ctrl** (changeable in settings) - cycle stage: 2/2 -> 4/4 -> 8/8 -> 16/8 -> OFF (the stage is remembered between sessions)
- **Right Alt** - show/hide a half-transparent stage label in the bottom-right corner (remembered too)

## Settings
- HUD label opacity / scale
- Debug console (off by default)
